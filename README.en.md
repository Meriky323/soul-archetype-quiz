## Why I built it

A common problem with personality quizzes is that users can often guess what an answer is trying to measure:

> “If I choose this option, I will look more rational / brave / creative.”

Once the intent becomes obvious, answers can shift from “what I usually do” toward “who I want to be”.

This project experiments with **situational choices** across different contexts, then combines those choices into a dimensional profile and an archetype result.

---

## Test structure

### 48 original situational questions

Instead of directly asking:

- “Are you creative?”
- “Are you action-oriented?”

the quiz places users in more concrete situations and asks what they would do.

### 8 behavioral dimensions

- Creativity
- Systematic Thinking
- Curiosity
- Action
- Resilience
- Influence
- Aesthetic Sense
- Autonomy

### Result experience

The result page includes:

- primary archetype
- secondary archetype
- 8-dimension radar chart
- dimension interpretation
- behavioral-style description
- shareable result card

---

## Design approach

The project is inspired by archetype ideas and borrows several common psychometric design concepts:

- dimensional scoring
- reverse items
- cross-context consistency
- response-quality checks

It is not intended as a clinical or professional psychological assessment.

The goal is simpler:

> **Keep the quiz playful, while making the scoring structure more coherent and less obvious to game.**
